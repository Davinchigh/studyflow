# Direction contract — StudyFlow app (Operate)

Development-only. Never copy into source or shipped assets.

Scope: the single-page StudyFlow app (`frontend/src/main.jsx`). Mode: Operate. Build path: code-led.
Chosen by the user from three directions: **Departure board**, raised by the *Quiet studio* standing exit.

**THESIS.** A study week read like a printed transit timetable: every task is a departure with a scheduled (planned) and an actual (studied) time. Refuses the category default of a sidebar, a greeting hero and a row of same-size stat cards.

**OWN-WORLD.** Deep ink-blue board header over a cool white ground; signal orange marks *now* and the one primary action; four route colours identify subjects; red, amber and green carry only overdue, due-today and done. One grotesk (Archivo) with tabular figures, set wider and tighter for headings. Hairline rules, no shadows on rows, no boxes inside boxes.

**STORY.** The student opens it, sees the next departure and starts the timer within seconds; scanning the board shows what is late, what is today and how planned time compares with time actually studied. A reviewer sees the core idea (planned ≠ studied) in the first viewport.

**FIRST VIEWPORT.** Board header (brand, nav, live clock, theme, profile). Below, the "Next departure" panel: status chip, subject route bar, task title at display size, due/planned/studied figures, Start focus (orange) and Mark done; on the right a large tabular countdown with a linear progress rule. Under it one status line of figures (overdue, today, next 3 days, planned left, studied this week), each a filter link. The board's first rows start above the fold on desktop.

**FORM.** Departure board, position 1 of 3 on the presented list. Raise from *Quiet studio*: generous spacing, a single accent doing real work, no ornament the timetable does not need. seed: none (unavailable) — impeccable's concept-seed was blocked by the session's permission policy; the direction was chosen by the user from a hand-built round.

**FINISH.** unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
